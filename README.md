## 🗺 怎么逛

- 想**像 GitHub 一样翻**：开 `.html`
- 想**当文献读**：开 `.md`
- 想**当数据玩**：开 `.json`（全量，含评论与操作事件）

> 图还链在 GitHub 上。上游 404 了文字还在，表情包另说。

## 🧾 免责声明（半认真）

公开 Issue 快照，仅供存档 / 学习 / 回味。  
文件夹名有点坏，与相关公司无官方关系。

自己挖坑：

```bash
uv run save-issues https://github.com/owner/repo/issues/N
```
